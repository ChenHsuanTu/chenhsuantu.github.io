內容

  1. 函數 max()最大值
  2. 函數 min()最小值
  3. 函數 sum() 總和
  4. 函數 sorted()排序(由小到大)
  5. 函數 map():對串列(迭代物件)的每個元素做指定函數的處理,處理後結果放入新的串列。
  6. map後的結果只能使用1次,要多次使用的話,要再用函數list處理。
  7. 函數 list():將可迭代物件(如字串、map結果)轉換為串列

一、max()最大值／min()最小值

In [1]:
# max可以放好幾個數字
max(22,25,24)
Out[1]:
25
In [2]:
# 也可以放陣列
max([22,25,24])
Out[2]:
25
In [3]:
# min 也是，可以放好幾個數字
min(22,25,24)
Out[3]:
22
In [4]:
# 也可以放陣列
min([22,25,24])
Out[4]:
22

二、排序： sorted() 由小到大

In [5]:
# sorted 只能放陣列
# sorted(22,25,24) -> 放數字會出錯
sorted([22,25,24])
Out[5]:
[22, 24, 25]
In [6]:
# 如果我想由大到小，要加入 reverse = True 的參數
sorted([22,25,24], reverse=True)
Out[6]:
[25, 24, 22]

三、 map() 函式是一個懶惰的個迭代器 (iterator)── 只做一次

1. 前情提要，split 是把「一段文字」，用空白格切割成「陣列」（陣列裡面還是文字）

In [7]:
s = '19 21 20'
s.split()
Out[7]:
['19', '21', '20']

2. 我想把陣列裡面文字變成整數，改怎麼做呢？

(1) 單純的字串 '21' ，可以透過 int() 變成整數

In [8]:
int('5')
Out[8]:
5

(2) 陣列不能直接用 int()。那只能把陣列裡每一個東西都拿出來做 int()。

把 list 裡面每個東西都一一拿出來，分別作運算的工具，就是 map()。

map 裡面第一個放函數「名稱」（所以不用加後面括號），第二個放陣列。

In [9]:
# int(s.split()) <- 這個不行，裡面不是字串 TypeError: int() argument must be a string, a bytes-like object or a real number, not 'list'
In [10]:
sp = s.split()
sp
Out[10]:
['19', '21', '20']
In [11]:
# 對 sp 的每個元素做 int ，寫法是 map(int, sp)。map 裡面第一個放函數「名稱」，第二個放陣列。
n = map(int,sp)
n # n 的長相很奇怪
Out[11]:
<map at 0x7f8445237790>

3. 直接做完 map 的結果，有些壞處……

(1) 樣子很奇怪（像上面）　<map at 0x79fdaeb8ccd0>

(2) map 很懶惰，只算執行一次（只能被消耗一次，所以算過後就消失了）

In [12]:
# 計算 n 第一次
sum(n)
Out[12]:
60
In [13]:
# 計算 n 第二次 -> 沒了
sum(n)
Out[13]:
0
In [14]:
# n 消失了
list(n)
Out[14]:
[]

4. 所以我們要用 map 算出來的陣列，要用 list() 把他存下來

In [15]:
n = list(map(int,sp))
n
Out[15]:
[19, 21, 20]
In [16]:
# 計算 n 第一次
sum(n)
Out[16]:
60
In [17]:
# 計算 n 第二次
sum(n)
Out[17]:
60
